## Instalasi Swap (ZRAM + Disk Swap)
Gunakan perintah di bawah ini untuk mengunduh dan menjalankan script instalasi:

```bash
wget https://raw.githubusercontent.com/wibusantun/Swap-Ram/main/zswap.sh && chmod +x zswap.sh
./zswap.sh
```
# Hapus Swap
```html
wget https://raw.githubusercontent.com/wibusantun/Swap-Ram/main/remove-zswap.sh && chmod +x remove-zswap.sh
./remove-zswap.sh
```
