## Instalasi Swap (ZRAM + Disk Swap)
Gunakan perintah di bawah ini untuk mengunduh dan menjalankan script instalasi:

```bash
wget -qO- https://raw.githubusercontent.com/wibusantun/Swap-Ram/main/zswap.sh | bash
```
```bash
curl -sO https://raw.githubusercontent.com/wibusantun/Swap-Ram/main/zswap.sh && chmod +x zswap.sh && ./zswap.sh; rm -f zswap.sh
```
